# Mini Task Tracker

A beginner-friendly project built with Next.js and Supabase.

## Features

- Add tasks
- View saved tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Store data in Supabase PostgreSQL
- Responsive dark UI

## Technology Stack

- Frontend: Next.js and React
- Backend: Next.js Server Actions
- Database: Supabase PostgreSQL
- Language: TypeScript
- Styling: CSS

## Installation

Install dependencies:

npm install @supabase/supabase-js server-only

## Database Setup

Open your Supabase dashboard.

Go to SQL Editor and execute:

    create table public.tasks (
      id bigint generated by default as identity primary key,
      title text not null
        check (char_length(trim(title)) > 0),
      completed boolean not null default false,
      created_at timestamptz not null default now()
    );

    alter table public.tasks enable row level security;

## Environment Variables

Create a .env.local file in the root directory.

Add your Supabase Project URL and server-side secret key.

Keep this file private.

## Run the Application

Run:

npm run dev

Open:

http://localhost:3000

## How It Works

1. The frontend displays the task list.
2. Server Actions receive form submissions.
3. The server communicates with Supabase.
4. Supabase saves or updates task records.
5. Next.js refreshes the displayed task list.

## CRUD Operations

Create: Add a task.
Read: Display tasks.
Update: Complete or undo a task.
Delete: Remove a task.

## Security

This is a learning project without authentication.
The Supabase secret key must remain on the server.
Do not deploy the application publicly without adding
authentication, authorization, and suitable access policies.
